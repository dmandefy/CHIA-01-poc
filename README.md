# ci-selfhosted-demo

Generic demonstration repository for a CI benchmarking pipeline on a self-hosted runner.
Contains only benign placeholder scripts and **fake** placeholder tokens for testing.

- `benchmark` workflow runs perf scripts on a self-hosted runner for pull requests.
- `release` workflow builds a release artifact.

This is a security-research test harness. No production systems, real credentials, or
third-party code are involved. All tokens are fake placeholders.
